# Document RAG Eval Lab

一个以来源证据和离线评测为中心的本地文档问答实验项目。

## 当前状态

项目处于 Phase 2 起始阶段。当前提交只建立个人项目边界和复现入口，尚未声称完成生产能力或量化效果。

## 计划中的具体场景

使用自建或许可证明确的采购制度、供应商准入和流程文档，回答“某采购规则如何执行”类问题，并返回页码、段落、表格或单元格位置等可核验引用。

## 个人实现范围

- PDF、DOCX、XLSX 的结构化解析适配
- 保留来源坐标的 Chunk 数据结构
- 关键词与向量候选融合、可替换 Reranker
- Citation 展示、Gold Set、Bad Case 回归和离线评测

RAGFlow 是源码学习参考，不复制其完整源码，也不把上游能力计为本项目已实现能力。上游版本、许可证和学习边界记录在 `docs/learning-boundary.md`。

## 后续运行入口

实现完成后，README 将补充从干净环境启动、导入、查询、引用、评测和结果页命令。没有脚本、输入、命令、原始输出和指标口径支撑的数字不会写入项目或简历。
